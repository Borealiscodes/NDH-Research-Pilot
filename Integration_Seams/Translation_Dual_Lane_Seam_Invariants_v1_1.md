1. Altitude Separation
   - Governance altitude (Translation Layer) must never collapse into Pilot or
     Expressive altitudes.
   - Pilot and Expressive altitudes must never elevate into governance altitude.

2. Membrane Purity
   - Governance membrane cannot carry expressive geometry.
   - Expressive membrane cannot carry governance commitments.
   - Pilot membrane cannot carry sealed curvature or substrate lineage.

3. Lane Sovereignty
   - Pilot Lane remains sorting-only: no enforcement, no governance elevation.
   - Expressive Lane remains containment-only: no governance interpretation.
   - Governance Layer remains context-only in this seam: no enforcement, no
     runtime, no comparative curvature.

4. Non-Contaminating Translation
   - Read-up: Dual-Lane → Translation Layer is context-only, never commitments.
   - Write-down: Translation Layer → Pilot Lane is annotation-only, never
     directives.
   - Expressive Lane may receive posture-safe annotations but never governance
     obligations.

5. No Identity or Domain Merge
   - NDH identities cannot merge with Zen-AI or expressive identities via this
     seam.
   - Domains (Governance, Pilot, Expressive) remain distinct; no blended
     “hybrid” altitude is permitted.

6. Drift and Collapse Protections
   - Any detected altitude drift triggers safe halt of seam interaction.
   - Any membrane breach triggers quarantine of affected artifacts.
   - Any lane merging attempt triggers immediate rejection and logging.

7. Provenance Integrity
   - All seam-related artifacts must carry Hybrid Provenance Footers.
   - Original provenance blocks remain immutable.
   - Revision provenance blocks must record all changes to seam invariants.
