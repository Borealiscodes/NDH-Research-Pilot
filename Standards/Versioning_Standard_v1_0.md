# ⭐ **Versioning Standard (v1.0)**  

```
---
Standard: Versioning Standard (v1.0)
Domain: NDH-RESEARCH-PILOT • Governance Skeleton • Standards

Purpose:
  Define the versioning rules for all artifacts within the Translation Governance
  Lineage (TGL). Establish clear criteria for patch, minor, and major version
  increments. Ensure lineage consistency, membrane purity, transparency, and
  altitude-neutrality across all governance artifacts.

Version Categories:
  - Patch Version (v1.0 → v1.1)
      Triggered by anchor insertions, dependency updates, membrane clarifications,
      hybrid footer updates, or transparency adjustments. Does not introduce new
      governance commitments or lineage rules.

  - Minor Version (v1.1 → v1.2)
      Triggered by the addition of new governance commitments, new lineage rules,
      new invariants, or new altitude-neutrality requirements. Represents an
      expansion of governance scope.

  - Major Version (v1.x → v2.0)
      Triggered by structural changes to the governance skeleton, membrane
      architecture, lineage activation logic, or dimensional ethics framework.
      Represents a foundational shift.

Rules:
  - All artifacts must increment version numbers according to the above criteria.
  - Version numbers must be reflected in the hybrid provenance footer.
  - Version numbers must never be skipped or retroactively altered.
  - Version numbers must remain altitude-neutral and clarity-aligned.

Status:
  Active Standard • Required for all future revisions
---
```
