# 🟦🟩🟪 **VM‑VEX Orb Version Dashboard (v1.0)**  
### *Visual Layer • Colored Orbs • Human‑Readable Only • Non‑Activating*

---

## ⭐ 1 — Purpose  
This dashboard provides a **visual‑only** representation of VM‑VEX’s ingestion, ecology, memory, GPU, and phase states using **colored orbs**.

It is meant for:

- developer clarity  
- visual sequencing  
- onboarding  
- documentation previews  

It is **not** machine‑readable and **never** parsed by VM‑VEX.

---

## ⭐ 2 — Orb Legend (Visual Layer)

| Phase / Domain | Orb | Meaning |
|----------------|------|---------|
| Foundations | 🟦 | Base sequencing clarity |
| Bundle Construction | 🟩 | Structural assembly |
| VM‑VEX Stabilization | 🟪 | Visibility + planning |
| VM‑VEX Internal Components | 🟧 | Internal map + ingestion |
| GPU Planning | 🔴 | Restricted (visual only) |
| CONSTELLATION | ⚫ | High‑altitude (restricted) |

Only the **first four** are used in VM‑VEX dashboards.

---

## ⭐ 3 — Orb Dashboard Fields

### **🟧 Ingestion Status**
Represents the ingestion grammar + internal map state.

- 🟧 grammar loaded  
- 🟧 grammar validated  
- 🟧 internal map present  
- 🟧 missing components  
- 🟧 stability flags  

---

### **🟪 Stability Ecology**
Represents ecology flags + altitude boundary checks.

- 🟪 ecology flags  
- 🟪 forbidden adjacency  
- 🟪 altitude drift  
- 🟪 stability ceilings  

---

### **🟧 Virtual Memory Map**
Represents VM envelope coherence.

- 🟧 region types  
- 🟧 envelope span  
- 🟧 stability ceilings  

---

### **🟪 GPU Envelope (Restricted Visual)**
GPU planning is visual‑only.

- 🔴 gpu envelope  
- 🔴 gpu ceilings  
- 🔴 gpu stability flags  

---

### **🟩 Phase Progress**
Represents sequencing phases.

- 🟦 foundation  
- 🟩 bundle  
- 🟪 stabilization  
- 🟧 internal  
- 🔴 gpu  
- ⚫ reserved
