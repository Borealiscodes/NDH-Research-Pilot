# 🟪 **VM‑VEX Orb Stability Ecology Dashboard (v1.0)**  
### *Visual Layer • Colored Orbs • Human‑Readable Only • Non‑Activating*

---

## ⭐ 1. Purpose  
This orb dashboard provides a **visual‑only** representation of VM‑VEX’s stability ecology domain using colored orbs.  
It is meant for:

- developer clarity  
- visual sequencing  
- documentation previews  
- onboarding  

It **never** enters machine‑readable lanes and **never** participates in ingestion.

---

## ⭐ 2. Orb Legend (Visual Layer)

| Domain | Orb | Meaning |
|--------|------|---------|
| Stability Ecology | 🟪 | Ecology + altitude boundaries |
| Forbidden Adjacency | 🟧 | Structural adjacency violations |
| Altitude Violations | 🔴 | High‑risk altitude drift |
| Ecology Flags | 🟦 | Informational stability indicators |

Only these orbs are used in this dashboard.

---

## ⭐ 3. Orb Dashboard Fields

### **🟪 Ecology Flags**
Represents stability‑ecology indicators.

- 🟦 ecology‑flags  
- 🟦 informational‑flags  
- 🟦 soft‑warnings  

---

### **🟧 Forbidden Adjacency**
Represents adjacency violations.

- 🟧 adjacency‑violations  
- 🟧 adjacency‑warnings  
- 🟧 adjacency‑critical  

---

### **🔴 Altitude Violations**
Represents altitude drift or ceiling breaches.

- 🔴 altitude‑violations  
- 🔴 altitude‑warnings  
- 🔴 altitude‑critical
