This artifact is **execution‑layer planning**, not **execution**.

# ⭐ 3 — GPU Integration Principles

## **3.1 Non‑Activation Rule**
GPU planning must **never**:

- bind  
- execute  
- allocate  
- dispatch  
- schedule  
- route  

It may only:

- describe  
- envelope  
- constrain  
- plan
