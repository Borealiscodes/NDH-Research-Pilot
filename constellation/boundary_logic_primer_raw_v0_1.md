# ⭐ **3. How CONSTELLATION Boundaries Work (Inferred)**

CONSTELLATION uses three mechanisms:

### **A. Altitude Partitioning**  
Each conceptual layer is treated as a separate “region,” similar to how constellation decision boundaries partition the IQ plane into Voronoi regions  [inferensys.com](https://inferensys.com/glossary/automatic-modulation-classification/signal-constellation-classification/decision-boundary).

### **B. Semantic Isolation**  
Symbolic constructs cannot modify scientific artifacts.  
Scientific artifacts cannot reinterpret symbolic cosmology.

This mirrors “semantic isolation” patterns used to prevent trust boundary collapse in AI systems  [hermes-codex.vercel.app](https://hermes-codex.vercel.app/ai-security/core-studies/trust-boundary-collapse/).

### **C. Routing Rules**  
Artifacts are routed to the correct altitude based on:

- purpose  
- content type  
- modeling domain  
- symbolic load

This ensures the repo remains coherent.
