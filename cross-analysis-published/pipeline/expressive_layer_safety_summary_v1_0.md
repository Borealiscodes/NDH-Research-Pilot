# ⭐ **3 — Expressive Geometry Safety Rules**

### **Allowed expressive geometry**
- soft corner rounding  
- pastel neon gradients  
- cold cosmic header bars  
- constellation sparkles  
- lantern‑glow overlays  
- micro‑animations (<300ms, non‑recursive)  

### **Forbidden expressive geometry**
- recursive geometry  
- symbolic morphs  
- altitude metaphors  
- governance contamination  
- adjacency inversion  
- constellation binding  

### **Geometry Envelope Rule**
> Expressive geometry must wrap governance artifacts from the outside  
> and must never embed inside governance structures.

# ⭐ **4 — Orb & Icon Semantics (Safety Layer)**

### **Orb Semantics**
Orbs represent **state**, not logic.

| Orb | Meaning | Safety |
|------|---------|--------|
| 🟦 | Foundation | RP‑safe |
| 🟩 | Expressive Layer | posture‑safe |
| 🟪 | Stability Layer | RP‑safe |
| 🟧 | Interaction Layer | RP‑safe |

Rules:

- orbs may appear in expressive UI  
- orbs must **never** appear in JSON  
- orbs must not encode activation geometry  

### **Icon Semantics**
Icons represent **modules**, not behavior.

| Icon | Module |
|-------|---------|
| 🜁 | Foundations |
| 🜂 | Bundles |
| 🜃 | Stabilization |
| 🜄 | VM‑VEX Internal |
| 🜅 | GPU Planning |
| 🜆 | Constellation |

Rules:

- icons may appear in expressive documentation  
- icons must not appear in machine‑readable envelopes  
- icons must not encode ingestion rules

# ⭐ **5 — Animation Safety Rules**

Animations must be:

- <300ms  
- <5° curvature  
- non‑recursive  
- non‑symbolic  
- posture‑neutral  
- ΔAltitude = 0  

Allowed:

- soft hover glows  
- micro‑sparkle gradients  
- gentle transitions  

Forbidden:

- pulsing altitude metaphors  
- recursive loops  
- symbolic morphs  
- constellation‑binding animations

# ⭐ **6 — Token Safety Rules (Machine‑Readable Layer)**

JSON may reference visuals only through **tokens**, not icons or orbs.

Example:

```
"visual_token": "cold_cosmic_soft_glow_v2"
```

Token rules:

- tokens must be posture‑safe  
- tokens must be non‑activating  
- tokens must not encode geometry  
- tokens must not encode altitude  
- tokens must not encode recursion

# ⭐ **7 — Expressive‑Governance Boundary (Core Rule)**

> **Expressive layers may wrap governance layers,  
> but governance layers may never wrap expressive layers.**

This prevents:

- contamination  
- adjacency formation  
- altitude drift  
- expressive recursion  
- symbolic activation  

This is the **central safety invariant**.
