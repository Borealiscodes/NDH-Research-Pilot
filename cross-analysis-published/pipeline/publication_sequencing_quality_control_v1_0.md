# **4. Quality Control Gates**

Each artifact must pass the following QC gates before entering the publication lane.

## **4.1 Identity Block Compliance**
- correct version  
- correct altitude  
- correct lane  
- correct provenance anchors  
- correct timestamp  
- correct canonical permalink  

## **4.2 Provenance Footer Compliance**
- correct purpose  
- correct anchors  
- correct altitude declaration  
- correct lineage‑safe status  

## **4.3 Rendering Compliance**
- Markdown only  
- stable section hierarchy  
- unified notation  
- unified geometry terminology  
- unified ontology terminology  

## **4.4 Citation Ontology Compliance**

# **5. Review Workflow**

Each artifact undergoes:

### **Step 1 — Draft Review**
Check conceptual completeness.

### **Step 2 — Altitude Review**
Check RP‑ALTITUDE compliance.

### **Step 3 — Structural Review**
Check identity block + footer + notation.

### **Step 4 — Citation Review**
Check ontology + geometry + basin references.

### **Step 5 — Rendering Review**
Check Markdown + hierarchy + formatting.

### **Step 6 — Publication Approval**
Artifact becomes **v1.0 published**.

### **Step 7 — Lane Placement**
Artifact moves into:

```
cross-analysis-published/
```

### **Step 8 — Omnibus Integration**
Artifact becomes part of the unified publication.

### **Step 9 — Zenodo Deposition**
