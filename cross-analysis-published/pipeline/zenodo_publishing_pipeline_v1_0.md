# ⭐ **5 — Versioning Scheme**

Publication-ready artifacts use:

```
v1.0 — First stable publication
v1.1 — Minor corrections (non-breaking)
v2.0 — Major revision (breaking)
```

Drafts use:

```
v1.0-draft
v1.1-draft
```

Only **v1.0+** enters the publication lane.

---

# ⭐ **6 — Rendering Rules**

### **A. Markdown only**  
No HTML, no PDF, no LaTeX in the repo.

### **B. Stable section hierarchy**  
```
# Title
## Section
### Subsection
```

### **C. Mathematical notation**  
Use standard Markdown + Unicode + fenced blocks.

### **D. Citation ontology references**  
Use the **Merged Citation Block v4.0**.

### **E. No conversational tone**  
Publication-ready artifacts must be academic.
