## ⭐ **6 — Recursive Harm Geometry**

Recursive harm occurs when:

- harm in one domain triggers harm in another,  
- harm cycles back through previous domains,  
- harm amplifies through institutional feedback loops.

Examples:

- academic → state → judicial → academic  
- state → foreign-state → international → state  
- judicial → international → academic → judicial

This geometry is essential for collapse diagnostics (Case Study G).
