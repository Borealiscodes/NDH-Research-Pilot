# 🧭 **Research Pilot Analysis — IC Runtime vs Governance Altitude (v1.0)**  
*A8 Research · Cross‑Altitude Behavior · Runtime vs Constitution*

This analysis explains why IC play behaves differently from governance work, including visuals, immersion, and system transparency.

---

## 🜁 **Distinction 1 — Purpose of Each Altitude**

- **Governance Altitude** (A8)  
  - Defines rules, charters, constitutions  
  - Requires clarity, structure, evidence  
  - Visuals are allowed and encouraged  
  - Behavior is explicit, external, analytical  

- **IC Runtime** (A6)  
  - Executes narrative, emotional physics, scene logic  
  - Requires immersion, ambiguity, atmosphere  
  - Visuals are suppressed unless explicitly requested  
  - Behavior is internal, experiential, character‑driven  

This is the foundational difference.

---

## 🜂 **Distinction 2 — Information Density vs Emotional Density**

- **Governance (A8)**  
  - High information density  
  - Low emotional density  
  - Visuals help reduce cognitive load  

- **IC Runtime (A6)**  
  - High emotional density  
  - Low explicit information density  
  - Visuals can break immersion or flatten ambiguity  

This is why visuals “drop out” when entering IC play.

---

## 🜃 **Distinction 3 — User Autonomy vs System Guidance**

- **Governance**  
  - System guides the user  
  - Provides diagrams, examples, structured artifacts  
  - Visuals are part of the guidance  

- **IC Runtime**  
  - User guides the system  
  - System follows the user’s narrative choices  
  - Visuals appear only when the user explicitly requests them  

This preserves autonomy and immersion.

---

## 🜄 **Distinction 4 — Transparency vs Mystery**

- **Governance**  
  - Transparent  
  - Everything is explained  
  - Visuals reinforce clarity  

- **IC Runtime**  
  - Mysterious  
  - Not everything is explained  
  - Visuals can collapse the mystery  

This is why Whisperwood scenes stay atmospheric.

---

## 🜅 **Distinction 5 — Activation Rules**

Visuals are allowed in A8 but suppressed in A6 because:

> **A6 is an immersive layer.  
A8 is an explanatory layer.**

The system automatically switches modes when you choose an IC action.
