# 🧭 **Research Pilot Analysis — Visual Mode vs IC Runtime Mode (v1.0)**  
*A8 Research · Emergent Behavior · Cross‑Altitude Diagnostics*

This analysis explains **why visuals appear** during governance work and **disappear** during IC play.

---

## 🜁 **Distinction 1 — Purpose of the Layer**

- **Governance Layer (A8)**  
  - Purpose: clarity, structure, evidence, examples  
  - Visuals: diagrams, examples, references  
  - Behavior: explicit, externalized, object‑level  

- **IC Runtime Layer (A6)**  
  - Purpose: immersion, ambiguity, emotional physics  
  - Visuals: suppressed unless explicitly requested  
  - Behavior: narrative, internal, atmospheric  

This is the core distinction.

---

## 🜂 **Distinction 2 — Visual Referent Availability**

Visuals only appear when the content has a **real‑world referent**:

- lantern diagrams  
- mist behavior charts  
- save‑state examples  
- compression deltas  
- rollback trees  

But IC play uses **fictional constructs**:

- Whisperwood mist  
- memory‑active lanterns  
- emotional physics pulses  
- spectral silhouettes  

These do not have real‑world referents, so visuals would be misleading.

---

## 🜃 **Distinction 3 — Immersion Protection Rule**

A6 runtime has a constitutional rule:

> **Do not break immersion with external visuals unless the user explicitly requests a reference.**

This prevents:

- tone disruption  
- atmosphere collapse  
- narrative dissonance  
- meta‑layer leakage  

It’s the same rule that prevents debug overlays from appearing during IC play.

---

## 🜄 **Distinction 4 — Altitude Transition Trigger**

Visual mode → IC mode transition occurs when:

- user chooses an IC action  
- narrative becomes first‑person or scene‑based  
- emotional physics activate  
- lantern hierarchy becomes active  
- unresolved threads begin to move  

At that moment, visuals are suppressed automatically.

---

## 🜅 **Distinction 5 — User Override**

You can always override suppression by requesting:

- **Whisperwood clearing reference**  
- **Lantern reference**  
- **Mist behavior diagram**  
- **IC scene concept art**  

This re‑enables visuals even inside IC play.
