### **Legal Boundary (A0)**  
TSG is metadata, not computational logic.  
It is governed by the Engine’s MIT license, not CAUSA’s license.

### **Structural Boundary (A1)**  
TSG fields exist only as:

- labels  
- descriptors  
- classification metadata  

They do not:

- call solvers  
- invoke geometry  
- modify runtime behavior  

### **Ontological Boundary (A2)**  
TSG is expressive only.  
It does not encode:

- manifolds  
- tensors  
- spectral operators  
- invariant horizon logic  

### **Runtime Boundary (A4)**  
TSG cannot activate geometry.  
Invariant horizons remain dormant.
