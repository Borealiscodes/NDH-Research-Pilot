### **Legal Boundary (A0)**  
The adaptor:

- is MIT‑licensed  
- is not a derivative work under CAUSA §5  
- references CAUSA but does not embed it  
- requires CAUSA license to be present but not merged  

### **Structural Boundary (A1)**  
The adaptor:

- is a standalone module  
- contains no CAUSA code  
- contains no CAUSA geometry  
- contains no CAUSA projections  
- is a pure interface scaffold  

### **Ontological Boundary (A2)**  
The adaptor may include:

- TSG descriptors  
- expressive metadata  
- classification fields  

But these do not encode computational geometry.

### **Runtime Boundary (A4)**  
The adaptor cannot:

- activate CAUSA  
- invoke NDH geometry  
- call invariant horizons  
- run spectral operators  

All runtime layers remain dormant.
