## ⭐ **2 — Purpose of the Bridge**

The Bridge allows:

- Dashboard users to **see** narrative‑zone artifacts  
- Dashboard users to **orient** toward holonomy curriculum  
- expressive skins to wrap narrative content safely  
- orb/icon grammar to label narrative modules  
- posture‑safe expressive geometry to decorate access panels  

But it **never**:

- ingests  
- parses  
- activates  
- routes  
- binds  
- creates adjacency  
- alters altitude  
- touches NDH geometry  

This is a **view‑only orientation layer**.
