## ⭐ 3 — Functional Zones

**Foundations Zone (🟦 / 🜁):**  
- View core governance artifacts (Map, Atlas, Codex, etc.)  
- Read-only, no activation, no routing.

**Closure Zone (🟪 / diagnostic pane):**  
- View Closure, Silence Directive, Ledger, Index, Compendium.  
- Lineage graph only; no reopening, no mutation.

**Expressive Zone (🟩 / Zen‑AI lane):**  
- Preview Neon‑Kawaii, Cold Cosmic, Pip skins.  
- All overlays posture‑safe, non‑recursive, non‑symbolic.

**Compatibility Zone:**  
- Inspect Backwards Compatibility v1.0 and Visual Grammar v2.0.  
- See how expressive assets are allowed to wrap governance artifacts.

**Machine Zone (JSON Inspector):**  
- View machine‑readable blocks (no icons/orbs).  
- Validate tokens, altitude neutrality, non‑activation flags.
