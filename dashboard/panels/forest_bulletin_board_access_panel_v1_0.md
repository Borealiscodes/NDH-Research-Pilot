## ⭐ **2 — Purpose of the Panel**

The panel allows the Dashboard to:

- **display expressive‑safe previews** of forest artifacts  
- **point toward** sticky‑note clusters  
- **wrap narrative content in posture‑safe expressive skins**  
- **label narrative modules using orb/icon grammar**  
- **provide orientation** without activation  

But it **never**:

- loads sticky‑note content  
- parses narrative‑zone geometry  
- activates expressive recursion  
- creates adjacency  
- alters altitude  
- binds forest artifacts to governance lanes  

It is a **window**, not a **portal**.
