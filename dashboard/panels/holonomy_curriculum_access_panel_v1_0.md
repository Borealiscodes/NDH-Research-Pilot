## ⭐ **2 — Purpose of the Panel**

The panel allows the Dashboard to:

- **point toward** the holonomy curriculum  
- **display orientation cues** from Direction Manifold  
- **show expressive‑safe previews** of teaching‑geometry modules  
- **wrap content in posture‑safe expressive skins**  
- **label modules using orb/icon grammar**  

But it **never**:

- loads curriculum content  
- parses teaching‑geometry  
- activates recursion  
- creates adjacency  
- alters altitude  
- routes through Direction Manifold  

It is a **window**, not a **portal**.
