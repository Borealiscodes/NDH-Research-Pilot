# ⭐ 3 — VM‑VEX Mission  
VM‑VEX is the **pre‑runtime ingestion engine** responsible for:

- validating internal components  
- enforcing stability ecology  
- defining ingestion grammar  
- mapping virtual memory  
- sequencing pre‑runtime operations  
- planning GPU adjacency (non‑activating)  

VM‑VEX **never executes**, **never binds**, and **never activates**.
