## ⭐ **2 — Purpose of the Panel**

The panel allows the Dashboard to:

- **point toward** expressive‑geometry artifacts  
- **display orientation cues**  
- **show expressive‑safe previews**  
- **wrap content in posture‑safe expressive skins**  
- **label modules using orb/icon grammar**  

But it **never**:

- loads expressive geometry  
- parses expressive geometry  
- activates expressive geometry  
- creates adjacency  
- alters altitude  
- routes through expressive manifolds  

It is a **window**, not a **portal**.
