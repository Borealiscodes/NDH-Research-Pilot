## ⭐ 2 — Tile Purpose

A Dashboard Tile built from this standard:

- **points toward** expressive‑ecology artifacts  
- **previews** sealed expressive geometry  
- **labels** modules using orb/icon grammar  
- **wraps** content in expressive‑safe skins  
- **integrates** with Dashboard v1.0  

But it **never**:

- loads expressive geometry  
- parses expressive geometry  
- activates expressive geometry  
- creates adjacency  
- shifts altitude  
- routes through expressive manifolds  

It is a **window**, not a **portal**.

## ⭐ 3 — Tile Rules (v1.0)

Each rule begins with a Guided Link.

- **Rule TS‑1 — Orientation‑Only**  
- **Rule TS‑2 — Zero Ingestion**  
- **Rule TS‑3 — Zero Activation**  
- **Rule TS‑4 — Expressive‑Safe Wrapping**  
- **Rule TS‑5 — Sealed Ecology Neutrality**  
- **Rule TS‑6 — ΔAltitude = 0**  
- **Rule TS‑7 — Adjacency Sealed**  

These rules are mandatory for any tile that references expressive geometry.
