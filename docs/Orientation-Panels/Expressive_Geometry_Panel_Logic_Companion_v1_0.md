## ⭐ 2 — Why This Companion Exists

The companion exists because:

- **Expressive Geometry Sealing**  
- **Safety Lattice Behavior**  
- **Domain Ecology Logic**  
- **Pinning vs Anchoring Theory**  

are **TISD‑altitude constructs**, not Research‑Pilot constructs.

But Research‑Pilot altitude *can* safely **point toward** them if:

- ΔAltitude = 0  
- adjacency = sealed  
- ingestion = none  
- activation = none  
- expressive wrapping = strict  
- posture alignment = strict  

This companion defines those rules.

## ⭐ 3 — Panel Logic Rules (v1.0)

Each rule begins with a Guided Link.

- **Rule PL‑1 — Orientation‑Only**  
  The panel may *point* but never *traverse*.

- **Rule PL‑2 — Zero Ingestion**  
  No expressive geometry is loaded or parsed.

- **Rule PL‑3 — Zero Activation**  
  No sealed geometry is activated or routed.

- **Rule PL‑4 — Expressive‑Safe Wrapping**  
  All previews use posture‑safe expressive skins.

- **Rule PL‑5 — Ecology Neutrality**  
  RP altitude must not alter expressive‑ecology behavior.

- **Rule PL‑6 — ΔAltitude = 0**  
  No altitude shift occurs in either direction.

- **Rule PL‑7 — Adjacency Sealed**  
  No adjacency to NDH geometry, governance, or teaching‑geometry.
