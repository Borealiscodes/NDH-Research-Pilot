## **4 — Formal Definitions (Public‑Facing)**

### **Expressive Clarity (NDH‑Internal Definition)**  
A linguistic mode that uses metaphor, analogy, or narrative to **illuminate underlying structure** without altering the structure itself.  
It is:

- boundary‑respecting,  
- reversible,  
- non‑prescriptive,  
- non‑activating,  
- adjacency‑safe.

### **Metaphor Hijacking (NDH‑Internal Definition)**  
A linguistic failure mode where metaphor or analogy **overwrites**, **collapses**, or **dominates** the underlying structure.  
It is:

- boundary‑collapsing,  
- irreversible,  
- prescriptive,  
- adjacency‑dangerous,  
- membrane‑breaching.
