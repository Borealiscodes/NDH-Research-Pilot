# ⭐ **2 — Binding Rules (v1.0)**

### **Rule 1 — EC Foundations Anchor All Routing**
All routing engines must reference EC foundations before altitude transitions.

### **Rule 2 — Holonomy Matrix Governs Curvature**
Routing decisions must use the holonomy matrix thresholds, not raw curvature.

### **Rule 3 — Liminal Band Is the Neutral Bridge**
All transitions between EC and Designer altitudes must pass through ΔAltitude = 0.

### **Rule 4 — Designer Altitudes Require Seal Checks**
Any routing toward A9–A12+ must check sealed‑governance proximity (Gs).

### **Rule 5 — Diagrammatic Maps Must Not Override Routing Engines**
Maps visualize routing; they do not determine routing.

### **Rule 6 — Reversibility Must Be Preserved**
All transitions must be reversible unless sealed‑layer proximity forbids it.
