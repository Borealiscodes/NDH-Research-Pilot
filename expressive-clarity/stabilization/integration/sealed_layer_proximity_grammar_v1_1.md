# ⭐ **3 — Updated Proximity Gradient Grammar**

### **Proximity Gradient (Updated)**

```
Gs_far     → EC Domains (A0–A3)
Gs_near    → Liminal–Diagnostic Band (ΔAltitude = 0)
Gs_contact → Designer Altitudes (A6–A12+)
```

### Gradient Behavior

- **Gs_far → Gs_near**  
  EC → Liminal transition  
  (reflective → diagnostic)

- **Gs_near → Gs_contact**  
  Liminal → Designer transition  
  (diagnostic → construction)

- **Gs_contact → Gs_near**  
  Designer → Liminal decompression  
  (construction → diagnostic)

- **Gs_near → Gs_far**  
  Liminal → EC stabilization  
  (diagnostic → reflective)

All transitions remain **non‑activating**.
