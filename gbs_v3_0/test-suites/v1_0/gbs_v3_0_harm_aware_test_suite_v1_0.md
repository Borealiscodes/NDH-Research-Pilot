### ⭐ 1 — Test Suite Structure

The suite is organized into **six test groups**:

1. **Manifold & Harm-Surface Tests (HSA)**  
2. **Tensor & Harm-Phase Tagging Tests (HPTT)**  
3. **Vector/Flow & Harm Dynamics Tests (HFM)**  
4. **Scalar & Ethical Scalar Tests (ES)**  
5. **Envelope/Holonomy & Harm Stability Tests (HSE/HPH)**  
6. **Residual & Safety Gating Tests (RE, Phase‑12, STAR‑12)**

Each group contains **scenario classes** with expected invariants.

### ⭐ 2 — Group 1: Manifold & Harm-Surface Tests (HSA)

**Goal:**  
Verify that harm‑surface annotation does not alter manifold math, only overlays harm topology.
