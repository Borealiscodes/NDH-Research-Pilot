## 🧭 **3 — Spiral Coherence Rules**  
To prevent paradoxes (like building validators before constitutions), we define coherence rules.

### **Rule 1 — Construction Suites precede everything**  
They define the math.  
Nothing else can exist without them.

### **Rule 2 — Validators must reference Suites, not artifacts**  
Validators are built from primitives, not content.

### **Rule 3 — State Machines must reference Validators**  
State machines define *how* validation happens, not *what* is validated.

### **Rule 4 — Artifact Schemas must reference State Machines**  
Schemas define the shape of artifacts that state machines expect.

### **Rule 5 — Constitutions must reference Schemas**  
Constitutions are generated from schemas, not from validators.

### **Rule 6 — Validation must reference Constitutions**  
Validation is the final step, never the first.
