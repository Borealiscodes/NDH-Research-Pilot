# 🌘 **2 — Holonomy Routing Classes**

Holonomy routing emerges when traversal interacts with curvature.  
HBRO catalogs four primary classes:

### **Class 1 — Arc Routing**
Soft curvature → gentle return‑path shift.

### **Class 2 — Helix Routing**
Altitude curvature → phase‑shifted return.

### **Class 3 — Mirror Routing**
Reflective curvature → inversion or twist.

### **Class 4 — Weave Routing**
Constellation curvature → multi‑element adjacency change.

These classes form the backbone of holonomy routing behavior.
