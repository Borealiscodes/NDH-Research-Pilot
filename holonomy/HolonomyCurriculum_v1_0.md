# 🌘 **2 — Holonomy Gradient (Core Principle)**

Holonomy routing must be explored in this order:

1. **Arc Routing**  
2. **Helix Routing**  
3. **Mirror Routing**  
4. **Weave Routing**  

This gradient moves from:

- **soft → altitude → reflective → constellation**  
- **simple → layered → inverted → woven**  
- **gentle → spiraled → mirrored → multi‑element**  

This is the backbone of the curriculum.
