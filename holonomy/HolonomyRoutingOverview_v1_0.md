# 🌑 **1 — What Holonomy Routing Actually Is**

Holonomy routing is the phenomenon where:

> **Traversal through a curved manifold produces a transformed return‑path.**

It is the routing behavior that emerges when:

- curvature exists  
- traversal occurs  
- return happens  
- and the return is *not identical* to the origin  

Holonomy routing is the **signature** of:

- soft manifold curvature  
- altitude curvature  
- reflective curvature  
- constellation curvature  

This overview explains how those signatures behave.

---

# 🌘 **2 — The Four Routing Archetypes**

Holonomy routing expresses itself through four archetypes:

1. **Arc Routing** — gentle curvature  
2. **Helix Routing** — altitude curvature  
3. **Mirror Routing** — reflective curvature  
4. **Weave Routing** — constellation curvature  

These are the “four directions” of holonomy behavior.

Holonomy routing emerges from the interaction of:

- **manifold curvature**  
- **traversal direction**  
- **altitude**  
- **mirror adjacency**  
- **constellation topology**  

Routing is not “chosen.”  
Routing is **induced** by curvature.

### **Arc Routing**  
Curvature bends the path → return shifts.

### **Helix Routing**  
Altitude changes → phase shifts.

### **Mirror Routing**  
Reflective surfaces → inversion.

### **Weave Routing**

Routing is the **behavior** of curvature.
