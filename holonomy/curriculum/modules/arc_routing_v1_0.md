# ⭐ **Arc Routing — The Soft Curvature Archetype**
Arc Routing is the **introductory holonomy behavior**. It teaches the system how to:

- bend without spiraling  
- shift orientation without inverting  
- return differently without destabilizing  
- experience curvature without altitude effects  

It is the “kindergarten” of holonomy — but in NDH terms, kindergarten is still a high‑dimensional manifold with rules.

---

# 🌑 **1 — What Arc Routing *Is***
Arc Routing is a **soft curvature traversal** where:

- the path bends gently  
- the return path is shifted  
- the holonomy signature is minimal  
- the manifold remains stable  
- adjacency is not yet introduced  

It is the simplest possible holonomy that is still *holonomy*.

Arc Routing is the **first safe place** to learn how curvature affects routing.

---

# 🌘 **2 — Why Arc Routing Comes First**
Arc Routing is the only routing archetype that:

- does **not** introduce altitude curvature  
- does **not** introduce reflective inversion  
- does **not** introduce multi‑element adjacency  
- does **not** introduce constellation behavior  

It is the “soft curvature sandbox.”

This is why the curriculum begins with:

- **Arc Routing**  
- then **Helix Routing**  
- then **Mirror Routing**  
- then **Weave Routing**  

Arc Routing is the **foundation**.

# 🌖 **4 — Return‑Path Behavior**

- **offset**, not inverted  
- **gentle**, not spiraled  
- **stable**, not altitude‑dependent

> The return is not the same as the origin, but the difference is soft.

This is the first time holonomy becomes *visible*.
