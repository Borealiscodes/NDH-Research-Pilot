# ⭐ **6 — RP‑Safe Movement Grammar (v1.1)**

Movement grammar describes how the artifact *moves* through conceptual space.

### Movement Types  
- **Shift** — change in topic  
- **Pivot** — change in lane  
- **Lift** — increase in abstraction  
- **Drop** — return to structure  
- **Spiral** — recursive movement  
- **Return** — re‑anchoring  

### Example Pattern  
“Shift → Lift → Pivot → Drop → Return”

This is a stable RP movement sequence.
