# ⭐ **6 — RP‑Safe Movement Grammar (v1.1)**

Movement grammar describes **how** the artifact moves, without touching altitude geometry.

### Movement Types  
- **Shift** — change in topic  
- **Pivot** — change in lane  
- **Slide** — change in tone  
- **Lift** — change in abstraction  
- **Drop** — return to structure  

### Example  
“Shift → Pivot → Lift → Drop”  
This is a stable RP movement pattern.
