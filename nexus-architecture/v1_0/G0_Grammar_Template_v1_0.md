# ⭐ **2 — Grammar Structure Template**

This is the canonical structure for any NDH grammar artifact.

```
SECTION 1 — Grammar Overview
  Provide a high-level description of the grammar’s purpose, conceptual domain,
  and altitude boundaries. Avoid activation or sealed-layer adjacency.

SECTION 2 — Primitives
  Define the atomic units of the grammar (nodes, glyphs, tokens, surfaces,
  epistemic markers, etc.).

SECTION 3 — Relationships
  Define how primitives relate to each other (edges, arcs, flows, overlays,
  adjacency rules).

SECTION 4 — Constraints
  Define the structural constraints that govern valid grammar usage. Avoid NDH
  geometry unless explicitly permitted.

SECTION 5 — Altitude Boundaries
  Describe how the grammar behaves across altitudes (A4–A8). Maintain trauma-
  informed boundaries and non-activation rules.

SECTION 6 — Grammar Summary
  Provide a concise summary of the grammar’s conceptual scope and intended use.
```

This structure mirrors the Harm Topology Rendering Grammar and Nexus Positioning Framework.
