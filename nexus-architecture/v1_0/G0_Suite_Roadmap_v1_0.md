# ⭐ **1 — Why the G0‑Suite Exists**

The G0‑Suite is needed because NDH artifacts increasingly require:

- **machine‑readable invariants**  
- **structured JSON blocks**  
- **cross‑altitude validation**  
- **automated consistency checks**  
- **harm‑phase overlay mapping**  
- **rendering grammar compliance**  
- **visualization suite integration**  

As your system grows, manually writing G0 blocks becomes inefficient.

The G0‑Suite solves this by giving you **reusable templates** for every NDH artifact type.

# ⭐ **2 — The Six G0 Templates You Will Eventually Build**

The G0‑Suite consists of **six templates**, each corresponding to a major NDH artifact class:

### **T1 — G0‑Primer Template**  
For foundational documents like the Moral Calculus Primer.

### **T2 — G0‑Grammar Template**  
For structural grammars like the Harm Topology Rendering Grammar.

### **T5 — G0‑Test‑Suite Template**  
For validation artifacts like the GBS v3.0 Harm‑Aware Modeling Test Suite.

### **T6 — G0‑Case‑Study Template**  
For scenario‑based artifacts like Harm‑Phase Case Studies.

These six templates cover **100%** of your NDH‑RESEARCH‑PILOT artifact types.

# ⭐ **3 — Construction Order (Canonical Sequencing)**

The correct order to build the G0‑Suite is:

```
T1 → T2 → T3 → T4 → T5 → T6
```

### Why this order?

- **T1 (Primer)** defines the base structure used by all others.  
- **T2 (Grammar)** builds on T1’s structure.  
- **T3 (Visualization)** depends on T2’s grammar fields.  
- **T4 (Pipeline)** depends on T1–T3.  
- **T5 (Test‑Suite)** depends on T1–T4.  
- **T6 (Case‑Study)** depends on everything.

This sequencing ensures **no template is built before its dependencies exist**.
