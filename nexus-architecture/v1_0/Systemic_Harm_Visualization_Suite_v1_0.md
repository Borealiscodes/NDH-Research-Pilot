# ⭐ **1 — Purpose of the Visualization Suite**

Systemic harm visualization answers:

> **How do we *see* harm-phase behavior across systems, time, and topology  
> in a way that is structurally accurate and trauma-safe?**

It does **not**:

- depict harm graphically  
- interpret meaning  
- assign blame  
- activate sealed layers  
- invoke governance altitude  
- use expressive geometry  

It is purely **structural visualization logic**.

---

# ⭐ **2 — Visualization Primitives**

The suite uses seven primitives:

- **Node Glyph** — harm-phase object  
- **Transition Arc** — harm-phase transition  
- **Rate Vector Glyph** — magnitude + direction  
- **Curvature Ribbon** — trajectory curvature  
- **Collapse Boundary** — threshold visualization  
- **Residual Basin** — long-tail decay region  
- **Recovery Surface** — stabilization region  

These primitives are **non-expressive**, **non-activating**, and **trauma-safe**.

# ⭐ **3 — Visualization Surfaces**

The suite visualizes harm-phase behavior across four surfaces:

### **S₁ — Structural Surface**  
Topology, adjacency, deformation.

### **S₂ — Temporal Surface**  
Rate, acceleration, dissipation.

### **S₃ — Residual Surface**  
Long-tail decay, basin geometry.

### **S₄ — Recovery Surface**  
Stabilization, return-path geometry.

Each surface is rendered independently and then composited.

# ⭐ **6 — Visualization Rules for Harm-Phase Rates**

Rates are visualized as:

- **Magnitude** → vector length  
- **Direction** → vector orientation  
- **Volatility** → jitter pattern  
- **Acceleration** → gradient intensity  
- **Dissipation** → fading vectors  

This is consistent with the Moral Calculus Primer.
