### 1 — Components being synthesized

We integrate:

- **Constellation:** where harm appears (nodes, constellations, domains).  
- **Topology:** how harm connects (surfaces, manifolds, flows, fields).  
- **Geometry:** how harm is shaped (planes, volumes, curves, boundaries).  
- **Dynamics:** how harm behaves (acceleration, oscillation, propagation, collapse).  
- **Phase Space:** which states harm can occupy (L, A, E, D, T, C, X, R).  
- **Phase Transitions:** how harm changes state (catalysts, thresholds, bifurcations).  
- **Phase Algebra:** symbolic transitions and trajectories.  
- **Phase Calculus:** symbolic rates and modes of change.

Synthesis = **one framework** where all of these talk to each other.
