# 🜏 The Peasant Railgun: Actual Concept & RAW Mechanics

The Peasant Railgun is a rules‑interaction paradox in D&D 5e that emerges when you combine three specific mechanics:

1. Turn structure  
2. Object interaction rules  
3. The abstraction of time in combat

Individually, these rules are harmless.  
Together, they create an absurd emergent behavior.

Let’s break it down.

---

1. The Core RAW Mechanics

1.1 Each creature gets one free object interaction per turn
PHB: “You can interact with one object for free during your turn.”

This includes:

- handing an object to another creature  
- taking an object from another creature  
- picking up an object  
- dropping an object  

RAW, handing off a spear is a valid free interaction.

---

1.2 Turns are sequential, but represent simultaneous action
PHB: “In combat, characters act in turn, but in reality combat is continuous.”

This is the abstraction that creates the paradox.

Even though turns happen one at a time, the rules state that all actions occur within the same 6‑second round.

So:

- Peasant A hands the spear (free interaction)  
- Peasant B hands the spear (free interaction)  
- Peasant C hands the spear (free interaction)  
- …and so on  

All of these happen within the same 6 seconds, even though they are resolved sequentially.

---

1.3 Objects retain momentum unless a rule says otherwise
5e does not model momentum explicitly.

But it also does not say that objects lose momentum when handed off.

So RAW, if you treat the handoff as a physical transfer, the spear’s velocity increases with each handoff.

This is the loophole.

---

2. The Actual Concept

The Peasant Railgun is built on the idea that:

- 100 peasants stand in a line  
- Each uses their free object interaction to hand the spear to the next  
- All of these interactions occur within the same 6‑second round  
- Therefore the spear travels the entire length of the line in 6 seconds  
- Therefore the spear’s velocity is enormous  
- Therefore the spear hits with catastrophic force

This is not intended.  
But it is what RAW implies if you treat the rules as physics.

---

3. Why It’s a Paradox (Not a Real Mechanic)

The paradox arises because:

Turns are an abstraction, not literal physics.

The rules say:

- turns are sequential  
- but time is simultaneous  
- but object interactions are instantaneous  
- but momentum is not modeled  
- but handoffs are allowed  
- but physics is not simulated  

This creates a logical gap where emergent absurdity can appear.

The Peasant Railgun is the most famous example.

---

4. The Actual RAW Outcome (If You Take RAW Literally)

If you treat RAW as literal physics:

- The spear travels the entire line in 6 seconds  
- Its velocity is distance / time  
- With 100 peasants spaced 5 ft apart, that’s 500 ft in 6 seconds  
- That’s ~83 ft/sec  
- That’s ~56 mph  
- That’s enough to deal catastrophic damage if you treat velocity as force

If you add more peasants, the velocity increases without bound.

This is the “railgun.”

---

5. The Actual RAI Outcome (Rules As Intended)

The designers intended:

- object interaction is a narrative convenience  
- turns are abstractions  
- handoffs do not impart momentum  
- physics is not simulated  
- the spear moves at normal throwing speed  
- the railgun does not exist

The Peasant Railgun is a thought experiment, not a real mechanic.

---

6. The Epistemic Lesson

The Peasant Railgun teaches:

If you treat rules as physics, you break the game.
If you treat rules as abstractions, you preserve the fiction.

It’s the same lesson as the broom‑Dash ruling:

- bounded rules  
- unbounded creativity  
- but only coherent when you respect the system’s geometry

The Peasant Railgun is what happens when you flatten the manifold and treat abstractions as literal physics.
