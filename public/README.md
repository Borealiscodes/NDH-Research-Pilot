## **1. Overview**
The **Borealis Emblem Rendering System** is a fully ASCII‑safe, non‑activating visual identity framework operating strictly within **NDH‑Research‑Pilot altitude**.  
It provides:

- a stable conceptual design  
- a constellation‑safe color palette  
- ASCII‑only diagrams  
- machine‑readable specifications  
- renderer‑support artifacts  
- PNG rendering guidelines  

All geometry, color, and metaphor rules are designed to avoid:

- routing semantics  
- governance posture  
- subsystem adjacency  
- activation cues  

This README introduces the system and links to all major artifacts.
