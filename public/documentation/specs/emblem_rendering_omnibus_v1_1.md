# **4. Blueprint Suite Lite Rendering Spec (v1.0)**  
### *Geometry & Stability Discipline*

Geometry allowed:

```
○   ◇   @
(circle, hexagon, spiral)
```

Geometry disallowed:

```
▲   →   ⇢   ✦
(triangle, arrow, routing, radiance)
```

Color rules:

- pastel gradients  
- muted tones  
- constellation‑safe palette only  

Metaphor rules:

- enso = presence  
- meadow = calm  
- hexagons = cooperation  
- celestial triad = evolution
