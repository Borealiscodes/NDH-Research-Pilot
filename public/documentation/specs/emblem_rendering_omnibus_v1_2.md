# **2. Contributor Guidelines (v1.2)**  
### *Non‑Activating, GitHub‑Safe*

Contributors must follow these rules:

### **2.1 Geometry Rules**
Allowed:

```
○   ◇   @
(circle, hexagon, spiral)
```

Disallowed:

```
▲   →   ⇢   ✦
(triangle, arrow, routing, radiance)
```

### **2.2 Color Rules**
Use only palette identifiers from:

- Color Bands v1.0  
- Machine‑Readable Spec v1.0  

### **2.3 ASCII‑Only**
All diagrams must be ASCII‑safe:

- no inline images  
- no SVG  
- no PNG  
- no Unicode art beyond emoji  

### **2.4 No Activation Cues**
Avoid:

- directional arrows  
- orbital paths  
- radiance lines  
- hierarchical framing  
- subsystem adjacency patterns  

### **2.5 No Governance Posture**
Avoid:

- shields  
- crowns  
- framing bars  
- authority‑implying geometry

# **5. Stability Enforcement Notes (v1.2)**  
### *Ensures contributors cannot accidentally activate geometry*

- All geometry must remain symbolic.  
- No element may imply motion.  
- No element may imply hierarchy.  
- No element may imply routing.  
- No element may imply subsystem adjacency.  
- No element may imply governance.  

These rules are mandatory for all contributions.
