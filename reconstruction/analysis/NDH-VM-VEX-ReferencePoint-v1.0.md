## ⭐ 2 — What VM‑VEX *Is*  
VM‑VEX is a **virtual ingestion engine** that consumes:

- machine‑readable bundles  
- altitude metadata  
- lane metadata  
- recursion ceilings  
- stability‑ecology flags  
- comparative geometry alignment  

VM‑VEX is **not** a renderer, GPU system, or runtime executor.  
It is a **virtual machine abstraction**.
