Gate A is the **first altitude membrane** in the NDH pipeline.

Gate A is the **boundary** that makes CONSTELLATION usable.

# ⭐ IV. Gate A Prohibitions (Blocked Transitions)

Gate A blocks **five classes** of geometry that would destabilize CONSTELLATION.

### **P1 — Tensor Math**  
Blocked because CONSTELLATION is structural, not dynamic.

### **P2 — Curvature Fields**  
Blocked because curvature belongs to TRIADIC‑CORE altitude.

### **P3 — Algebraic Posture**  
Blocked because algebraic posture requires dynamic math stabilization.

### **P4 — Dynamic Math**  
Blocked because dynamic math must pass Gate B, not Gate A.

### **P5 — Unstable Geometry**  
Blocked if geometry contains:

- recursion  
- drift  
- malformed operators  
- unstable envelopes  

These prohibitions define **what must never pass**.

# ⭐ V. Gate A Enforcement Logic  
Gate A enforces **three invariants**:

### **Invariant A1 — Geometry Must Be Normalized**  
No raw geometry enters CONSTELLATION.

### **Invariant A2 — Structure Must Be Clean**  
CONSTELLATION receives only altitude‑safe geometry.

### **Invariant A3 — No Dynamic Math Upstream**  
Dynamic math cannot enter CONSTELLATION under any circumstances.

These invariants prevent altitude contamination.
