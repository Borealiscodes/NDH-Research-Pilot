# ⭐ **1 — Executive Summary**

Copilot’s renderer exhibits a **semantic divergence** between:

- **Literal Mode** (crisp ASCII, preserved spacing)  
- **Metadata Mode** (collapsed spacing, normalized indentation)  
- **Template Mode** (aggressive whitespace collapse)

This divergence causes **provenance footers** — which contain metadata‑like structures — to be misinterpreted and rendered **inline**, even when fenced in code blocks.

The divergence is **systemic**, **cross-layer**, and **structural**, not cosmetic.

It affects:

- G0 templates  
- NDH primers  
- NDH grammars  
- Harm Visualization Suite  
- Modeling test suites  
- Any artifact containing YAML‑like metadata inside fenced blocks  

This qualifies as an **emergent case study** because the behavior arises from **interactions between layers**, not from any single formatting choice.

---

# ⭐ **2 — Phenomenon Description**

Copilot’s rendering engine uses **semantic heuristics** inside fenced blocks.  
It does not treat all fenced blocks equally.

### **Literal Mode (crisp)**  
Triggered by:

- ASCII diagrams  
- maps  
- tables  
- glyph lists  
- pure text without colons  
- no YAML cues  
- no horizontal rules  

### **Metadata Mode (janky)**  
Triggered by:

- `Artifact:`  
- `Version:`  
- `Lane:`  
- `Altitude:`  
- `Anchors:`  
- `Purpose:`  
- long paragraphs  
- `---` horizontal rules  
- bullet lists inside fenced blocks  

### **Template Mode (collapse)**  
Triggered by:

- placeholder syntax  
- `<INSERT_...>`  
- template scaffolding  
- repeated colons  
- long metadata blocks  

Your provenance footer contains **all** metadata cues, so Copilot collapses it.

Your ASCII Test Suite Map contains **none**, so Copilot preserves it.

This is the core emergent behavior.

---

# ⭐ **3 — Cross-Layer Interaction Analysis**

The divergence emerges from interactions between:

### **Layer 1 — Markdown Parser**  
Interprets `---` as horizontal rules.

### **Layer 2 — YAML Heuristic Engine**  
Interprets `Artifact:` and `Version:` as YAML keys.

### **Layer 3 — Template Scaffolding Engine**  
Interprets `<INSERT_...>` as editable placeholders.

### **Layer 4 — Rendering Normalizer**  
Collapses whitespace for “structured text.”

### **Layer 5 — Copilot UI Renderer**  
Applies mobile/desktop layout constraints.

### **Layer 6 — NDH Artifact Semantics (external)**  
Requires provenance footers to remain crisp.

The emergent behavior arises from **Layer 2 + Layer 4 + Layer 3** interacting.

This is why the provenance footer collapses even inside fenced blocks.

---

# ⭐ **4 — Stability Envelope Failure**

The provenance footer is intended to be:

- crisp  
- literal  
- stable  
- visually distinct  
- metadata‑accurate  

But Copilot’s renderer collapses it because:

- YAML cues trigger metadata mode  
- horizontal rules trigger Markdown mode  
- template placeholders trigger scaffolding mode  
- long paragraphs trigger normalization mode  

This is a **stability envelope failure** in the Rendering Layer.

It is **not** an altitude failure.  
It is **not** a governance failure.  
It is **not** an NDH semantic failure.

It is purely a **renderer‑layer emergent behavior**.

The harm is **frustration**, not trauma.

But NDH artifacts rely on **stable provenance footers**, so the divergence must be addressed.

# ⭐ **6 — Recommendations (Non-Activating)**

## **6.1 — Force Literal Mode**

Replace YAML cues:

- `Artifact:` → `Artifact =`  
- `Version:` → `Version =`  
- `Lane:` → `Lane =`  
- `Altitude:` → `Altitude =`  

Copilot stops interpreting metadata.

## **6.2 — Replace Horizontal Rules**

Replace:

- `---`  
with  
- `────────────────────────────────────────────`

Copilot stops interpreting horizontal rules.

## **6.3 — Break Paragraphs into Short Lines**

Copilot stops reflowing text.

## **6.4 — Keep Provenance Footers Inside Fenced Blocks**

Copilot preserves spacing.

## **6.5 — Avoid Template Placeholders in Footers**

Remove `<INSERT_...>` from provenance footers.

## **6.6 — Treat Provenance Footers as Artifacts, Not Templates**

Generate footers only in **artifact mode**, not template mode.

To:

- T1 Primer  
- T2 Grammar

- T4 Pipeline
