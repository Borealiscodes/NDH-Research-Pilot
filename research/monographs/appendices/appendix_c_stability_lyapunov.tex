\begin{definition}[Thermodynamic Dissipation Invariant]
Let $F : \M \to \mathbb{R}_{\ge 0}$ denote the variational free-energy functional evaluating state alignment across activation, curvature, and entropy components. A discrete state transition $s_t \mapsto s_{t+1}$ satisfies \textbf{Lyapunov Dissipation} if and only if:
\begin{equation}
  F(s_{t+1}) \le F(s_t)
\end{equation}
Replacing this functional check with static hardware power ceilings (e.g., $\text{power\_mw} \le 500$) constitutes a category error that permits silent semantic divergence while reporting valid execution telemetry.
\end{definition}
