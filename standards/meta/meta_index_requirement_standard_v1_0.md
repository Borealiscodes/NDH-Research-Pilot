# ⭐ NDH‑RESEARCH‑PILOT Formal Standard  
## **Meta Index Requirement Standard (MIRS) v1.0**  
### *When Meta Indexes Are Required in NDH Construction*

---

## 🌑 **1 — Standard Identity**

- **Name:** Meta Index Requirement Standard (MIRS)  
- **Version:** v1.0  
- **Altitude:** Expressive‑Clarity (governing)  
- **Lane:** NDH‑RESEARCH‑PILOT / standards / meta  
- **Purpose:**  
  Define the conditions under which NDH artifacts **must** include a Meta Index to prevent drift, duplication, altitude leakage, curvature activation, adjacency creep, and recursion instability.

---

## 🌘 **2 — Core Principle**

A Meta Index is required whenever an NDH artifact:

1. **contains terminology**,  
2. **crosses altitudes**, or  
3. **forms adjacency or recursion**.

If any of these three conditions are true, a Meta Index is mandatory.

---

## 🌗 **3 — Mandatory Meta Index Conditions**

### **3.1 Terminology Expansion**
A Meta Index is required when an artifact:

- defines new terms  
- expands existing terms  
- creates a lexicon  
- creates a glossary  
- creates an omnibus  
- creates a diagnostic vocabulary  

This includes:

- **Lexicon Skeleton**  
- **Lexicon Entries**  
- **Glossary**  
- **Diagnostic Terminology Omnibus**  

Language is curvature‑sensitive.  
Therefore, language requires indexing.

---

### **3.2 Cross‑Altitude Interaction**
A Meta Index is required when an artifact spans:

- expressive‑clarity  
- diagnostic  
- hyperstructure  
- VM‑VEX  
- NDH‑Algebra  
- SCI‑80  
- Capstone  
- MRI  
- Cosmology  
- Hex System  
- Descent Observation  

Cross‑altitude artifacts must be indexed to prevent:

- altitude collisions  
- membrane leakage  
- operator activation  
- curvature drift  

Examples:

- Holonomy → Diagnostics  
- Diagnostics → RMES  
- RMES → Hyperstructure  

---

### **3.3 Adjacency or Recursion Formation**
A Meta Index is required when an artifact:

- forms conceptual adjacency  
- forms recursion  
- forms reflection  
- forms constellation behavior  

This includes:

- routing systems  
- diagnostic systems  
- morphology systems  
- terminology systems  
- constellation maps  

Adjacency and recursion are curvature‑active.  
Meta Indexes prevent accidental activation.

---

## 🌖 **4 — Optional Meta Index Conditions**

A Meta Index is recommended (but not mandatory) when:

- the artifact is expected to grow beyond 20 terms  
- the artifact is expected to be referenced by multiple subsystems  
- the artifact is expected to be used in RMES  
- the artifact is expected to be used in NDH‑Algebra  
- the artifact is expected to be used in hyperstructure diagnostics  

This ensures long‑term stability.

---

## 🌕 **5 — Conditions Where Meta Indexes Are *Not* Required**

A Meta Index is **not** required when the artifact is:

- purely geometric  
- purely mathematical  
- purely operator‑based  
- purely manifold‑based  
- purely diagrammatic  
- purely narrative  
- purely phenomenological  

These artifacts have **hard boundaries** and do not drift.

Examples:

- VM‑VEX altitude membranes  
- NDH‑Algebra operator families  
- SCI‑80 invariants  
- Capstone geometry  
- MRI curvature maps  
- Hex System adjacency grids  

These systems are self‑indexing.
