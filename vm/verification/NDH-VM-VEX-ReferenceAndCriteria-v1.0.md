# ⭐ IV. VM‑VEX Core Criteria  
VM‑VEX must satisfy **seven criteria** to be stable:

### **1. Deterministic Execution Kernel**  
No recursion.  
No dynamic math.  
No tensor potentials.  
No Verdant Deep geometry.

### **2. Schema‑Strict Gate Interpreter**  
Must consume machine‑readable JSON exactly.  
No inference.  
No drift.  
No optional fields.

### **3. Verification Layer Integration**  
Must execute:

- VO1 — Aperture Validity  
- VO2 — Prohibition Clearance  
- VO3 — Stability Thresholds  
- VO4 — Activation Conditions  
- VO5 — Output Contract Guarantees  

### **4. Altitude Boundary Enforcement**  
Must block:

- geometry leakage into structure  
- structure leakage into dynamic math  
- dynamic math leakage into reconstruction  

### **5. Non‑Absorptive Architecture**  
Must not absorb:

- Soft‑80D manifold  
- operator families  
- spiral loops  
- harmonic layers  
- Omega‑7+ recursion  
- tensor potentials  
- consensus dynamics  

These belong to VM 2.0 or NDH‑TIDS, not VM‑VEX.

### **6. Deterministic Verdict Engine**  
Must produce:

```
VALID
INVALID
```

With enumerated failure modes.

### **7. Clean Execution Cycle**  
Must run:

```
Load Gate → Validate → Enforce → Log → Return
```

No bloom.  
No spiral.  
No harmonic alignment.  
No dissolution cycle.
